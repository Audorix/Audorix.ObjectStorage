# Support

This project is in public preview. Use GitHub Issues for reproducible bugs and feature requests, and GitHub Discussions for usage questions if Discussions are enabled.

For an actionable bug report, include the package version, .NET SDK/runtime, operating system, metadata provider, client and version, expected behavior, observed behavior, and a small reproduction. Remove credentials, signed URLs, customer data, and sensitive object names first.

There is no guaranteed response time or commercial support commitment for the preview release.
